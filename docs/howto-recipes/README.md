# How-to recipes

Gold walkthroughs for the DMX Core 100 docs copilot. **Not published** to
docs.dmxcore.com.

Add a file here whenever a real installer question shows up (phone, email,
ticket, or chat). A later review marks which ones are likely in the field;
those become eval cases and, if they earn it, public Common Tasks.

There is almost no historical ticket corpus. Empty (except the template and
one synthetic example) is expected.

## For humans

1. Drop the email / ticket / notes into a chat in this repo.
2. Ask to **add a how-to recipe** (the agent follows `AGENTS.md`).
3. Skim the new file: redact anything that slipped through, set `status`.

## Status

| Value | Meaning |
|-------|---------|
| `candidate` | Drafted from a real interaction; not reviewed yet |
| `likely` | You think installers will hit this often |
| `confirmed` | Seen more than once, or you are sure |
| `skip` | Keep for history; do not use as eval / Common Task |

## Files

- `AGENTS.md` — how an AI must format a recipe from a support interaction
- `_template.md` — copy this
- `YYYY-MM-DD-short-slug.md` — one recipe per file
