---
title: Common Tasks
---

Guides for frequently performed operations on the DMX Core 100.

- [Move Data Between DMX Core 100 Units](/dmx-core-100/common-tasks/move-data-between-dmx-core-100-units) - copy a backup from one unit to another by USB stick, Web UI, or cloud backup.
- [Play a Cue over OSC](/dmx-core-100/common-tasks/play-a-cue-over-osc) - fire saved cues from show-control software, a console, or an OSC panel.
- [Set a Static IP on the Touchscreen](/dmx-core-100/common-tasks/set-a-static-ip) - give an Appliance a fixed address from the touchscreen, for standalone operation with no DHCP server.
- [Upgrade software](/dmx-core-100/configuration/software-updates) - pick a current build on an Appliance, Windows, or macOS; Snap Linux updates outside the app.
